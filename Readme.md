# Sentiment Analysis on Tweets

This project performs sentiment analysis on tweets using Natural Language Processing (NLP) and Machine Learning techniques.

## 🔹 Technologies Used
- Python
- NLP
- Machine Learning
- TF-IDF
- Logistic Regression
- SVM
- AdaBoost
- XGBoost

## 🔹 Workflow
1. JSON data preprocessing
2. Text cleaning
3. Automatic sentiment labeling (VADER)
4. TF-IDF feature extraction
5. Model training and evaluation

## 🔹 Sentiment Classes
- 0 → Negative
- 1 → Neutral
- 2 → Positive

## 🔹 Models Used
- Logistic Regression
- Naive Bayes
- Linear SVM
- Decision Tree
- AdaBoost
- XGBoost
